# Money Map

Money Map is a simple, local-first bill planner PWA. It helps track expected income, regular bills, rent, annual reminders, variable payments, and payment windows.

## Features

- Monthly, annual, one-off, variable, and expected-window bills
- Working-day and England/Wales bank-holiday adjustments
- Calendar and list views
- Local history snapshots and JSON backup/restore
- Theme and dark-mode options

All plan data is stored in the browser unless you choose to export a backup.
